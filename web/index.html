What the measurements cover

RIPEstat’s Canadian country code identifies the registration. A network can use Canadian-registered ASNs in several countries. The routing flag comes from the country report. The prefix breakdown uses a separately dated RIS dump and includes non-default prefixes seen by at least ten RIS peers. A zero means none met that threshold.
